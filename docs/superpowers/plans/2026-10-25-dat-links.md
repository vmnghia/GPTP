> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PyDAT's TXT text (copy, paste, import, export), Jump buttons, "Used by" and name overrides on the editor's Data page.

**Architecture:** Core gets three table-driven pieces beside part 1's formats: `DatText` (PyMS's TXT coders per file), `DatRefs` (PyDAT's references and the "Used by" search) and `NameOverrides` (PyDAT's override files, kept in the exe). The document gains name overrides and text edits as single undo steps. The App adds the menu items, a TXT menu, the overrides dialog, Jump buttons through `DatFields.ReferenceField`, and a "Used by" panel under each tab.

**Tech Stack:** C# .NET 8, xUnit (+ Xunit.SkippableFact), WinUI 3 built in code (no .xaml); Python 3 with the PyMS clone only to make the golden fixtures.

## Review Focus

- Text from Notepad or PyDAT's own files: CRLF line ends, a UTF-8 BOM, trailing spaces — parses as PyMS's text does (Task 2 test `ParsesCrlfBomAndTrailingSpace`).
- A paste of another file's entry (a Weapon onto a unit) is refused with PyMS's message and changes nothing (Task 2 test `ApplyRefusesTheWrongType`; Task 5 test `PasteOfTheWrongTypeChangesNothing`).
- A partial entry (a sub-tab copy, or a hand-edited import listing a few keys) changes only those properties, and a compound value given in part is refused (Task 2 tests `ApplyChangesOnlyListedProperties`, `ApplyRefusesAHalfCompound`).
- An override name with a colon, leading spaces or an empty text: a colon and spaces kept as PyMS keeps them; an empty name removes the override (Task 4 tests `OverrideKeepsColonsAndSpaces`, `EmptyNameRemovesTheOverride`).
- A "Used by" sound range written backwards (end < start) matches nothing, as PyDAT; a Jump on None or past the end is disabled (Task 3 test `BackwardsRangeMatchesNothing`; Task 7 by reading).

### Task 2: Parsing and applying text

**Files:**
- Modify: `tools/ManifoldEditor/Manifold.Core/Data/Dat/DatText.cs`
- Test: `tools/ManifoldEditor/Manifold.Core.Tests/DatTextImportTests.cs`

**Interfaces:**
- Produces:
  - `sealed record TextEntry(string Type, int? Id, int Line, IReadOnlyList<(string Key, string Value, int Line)> Values)`
  - `sealed class DatTextException(string message, int? line) : Exception(message)` with `int? Line`
  - `DatText.Parse(string text) → IReadOnlyList<TextEntry>` (throws `DatTextException`)
  - `DatText.Apply(DatFile file, IReadOnlyList<TextEntry> entries, int? onto = null) → (DatFile File, IReadOnlyList<int> Changed)` (throws `DatTextException`; `onto` requires exactly one entry and ignores its id)

Rules (PyMS `parse_text` and `import_data`): strip a leading BOM; split on `\r\n` or `\n`; drop `#...` comments and trailing whitespace; a header `^\s*(\w+)\((\d+)?\):\s*$`; a value `^\s*(\w+)(?:\.(\w+))?\s+(\d+|True|False)\s*$`; refusals "Missing header before defining properties", "Unexpected line, expected a header or a property definition", "Entry N already exists", "Entry N is empty", "No entries found", "Entry missing id" (when not pasting), "Invalid entry id (must be between 0 and C, got N)", "Invalid type (expected 'X', got 'Y')", "Unrecognized property 'K'", "Invalid flag name F" (accepting `flag_0x<hex>` of any width), "Hit Points missing `whole` value" (and PyMS's other compound texts), a value past its field's type. A key for a property the entry doesn't cover is refused as unrecognized, as PyMS's `allowed=False`. Each refusal carries the 1-based line it found.
